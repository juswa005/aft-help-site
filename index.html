Step 1 of 5

Installing & Opening the System

ANINAW runs right on your laptop or desktop inside Docker Desktop. Follow the tab for your computer below.

  1. 1
    Install Docker Desktop

    Download and install Docker Desktop for Windows from docs.docker.com/desktop. Open Docker Desktop and wait until the bottom-left / tray icon turns green (running).

  2. 2
    Run the One-Click Installer (or Docker Compose)

    Open the AFT project folder, open the scripts folder, and double-click install_windows.bat. (If Windows asks for Administrator permission, click Yes.) If your computer needs a restart to finish WSL/Docker setup, restart and let it resume automatically.

  3. 3
    Open ANINAW in Your Browser

    Wait 2–5 minutes on the very first launch while Docker downloads the app files. Your browser will open automatically, or you can visit http://localhost:5173 (or use the new Automated Fund Tracker shortcut on your Desktop).

  1. 1
    Open the Installer

    Open the AFT project folder, open scripts, and double-click install_mac.command. It automatically checks for Homebrew and Docker Desktop, installs them if missing, and starts Docker.

  2. 2
    Allow Docker & Wait for First Launch

    If macOS asks for your Mac password or permission, approve it. Wait a few minutes on the first run for the app containers to finish setting up.

  3. 3
    Open ANINAW

    Your browser will open http://localhost:5173 automatically (and a shortcut is saved on your Desktop).

  1. 1
    Install Docker & Run the Setup Script

    Make sure Docker Engine + Docker Compose are installed, then run the setup script inside the project folder:

    Linux Terminal 
    chmod +x scripts/install_linux.sh && ./scripts/install_linux.sh
  2. 2
    Open in Your Browser

    Visit http://localhost:5173 once the containers finish starting.

Using only a single docker-compose.yml file (without full source code)?

If your organization received only a single docker-compose.yml (or docker-compose.prod.yml) file:

  1. Install and open Docker Desktop and wait until it says Running.
  2. Put that compose file inside its own dedicated folder (for example, AFT-System).
  3. Open Terminal / Command Prompt inside that folder and run:
Start ANINAW 
docker compose up -d

Next time you turn on your computer, open Docker Desktop (or click Start on the project inside Docker Desktop) and go to http://localhost:5173.

Where all your records are safely stored:

Your database lives in data/postgres/ (or Docker’s pgdata volume), receipts & logos live in data/uploads/, and a live Excel-ready log stays updated in data/reports/transactions_log.csv. Never delete the data/ folder unless you want to erase everything!

First Login & 5-Minute Setup

When you open ANINAW for the first time, sign in using the default administrator account, then change the password right away.

Default Login Details

Web Address
http://localhost:5173
Default Username
admin
Default Password
admin123

Multi-organization setup? Your platform administrator signs in with superadmin / superadmin123 (and creates each org’s own Admin account from the Superadmin portal).

First 4 Things To Do After Logging In

  1. 1
    Change the Default Admin Password

    Go to Settings → Security, click Change Password, and save a password your officers will remember (write it in your org handover notebook or password manager!).

  2. 2
    Set Your Organization Name, Acronym & Logo

    Go to Settings → Organization, fill in your Organization Name and Acronym, upload a logo (PNG/JPG/WebP under 5MB), and click Save Changes. This logo appears on your printed PDF reports.

  3. 3
    Create Accounts for Your Treasurer & Auditor

    Go to Settings → User Management and click Add User so each officer has their own username and role instead of sharing the admin login.

  4. 4
    Set Beginning Balances (If Carrying Over Funds)

    If your organization already has starting cash from last semester, open Ledger → Other Assets and click Establish Beginning Balance.

Step 3 of 5

Using the System Day-to-Day

Follow this simple order whenever your organization runs events, handles money, or prepares financial statements.

Role 1

ADMIN

Full control of the organization workspace. Can manage settings, add/remove users, reset forgotten passwords for Treasurers/Auditors, view Audit Logs, and record transactions.

Role 2

TREASURER

Day-to-day finance operator. Creates events, manages accounts, logs transactions with receipts, and updates Supplies, PPE, and Inventory ledgers.

Role 3

AUDITOR

Read-only reviewer. All add/edit/delete forms are hidden so records stay safe. Can inspect reports, receipts, Audit Logs, and Transaction Edit History.

1. Dashboard

Automatic Financial Overview

Your homepage automatically calculates Cash on Hand, Cash in Accounting, total income/expenses, budget utilization, and liquidation reminders. You never type directly into the summary boxes.

2. Events & Accounts

Set Up Events First

  1. Open Events → New Event before spending money on a project (enter name, dates, allocated budget, and fund source).
  2. Check Accounts for standard titles like 1010 Cash on Hand or 4010 Food Expense. Add custom ones with Add New Account.
3. Journal

Recording Transactions & Receipts

Click New Entry and pick one of the 5 transaction modes:

  • Income / Expense: Money received or spent.
  • Accounting Cash Flows: Deposits, Withdrawals, or cash moves.
  • Supplies / PPE: Buying supplies or equipment.
  • Liabilities: Borrowed money or paid debt.
  • To Collect: Receivables owed to or paid back to the org.

Receipt rule: Attach a clear PNG, JPG, or PDF receipt (max 5MB). Made a mistake? Use Void or Edit so the audit trail stays intact.

4. Ledger & Budget

Tracking Items, Assets & Funds

  • Supplies & Inventory: Use New Item to add items, (-) when supplies are used, or Sell Item for merchandise.
  • PPE (Equipment): Register assets with useful life & salvage value—monthly depreciation calculates automatically.
  • Fund Management: Use Add Fund Source → Save Budget to monitor overall funds.
  • Documents: Store liquidation/withdrawal forms under General Documents; Journal receipts appear automatically in Ledger Receipts.
Generating Official Reports & Excel Logs

Go to Financial Reports, choose your date range, and view the Statement of Assets and Liabilities, Statement of Activities, or Statement of Cash Flows. Click Export CSV or Download PDF anytime—and remember that data/reports/transactions_log.csv inside your project folder also updates live for Excel!

Step 4 of 5 • Troubleshooting

System Feeling Slow? Easy Fixes

If pages are taking too long to load or buttons feel sluggish, try these simple, non-technical steps in order. None of these steps will delete your records.

Good news first:

A slow screen almost always means your computer is temporarily busy or out of memory—it does not mean your database is corrupted or your data is lost.

Fix 1 • Safest First Step

Restart the App in Docker Desktop

Just like a phone or browser, restarting the app clears temporary sluggishness while keeping every transaction and receipt untouched.

  1. 1

    Open the Docker Desktop window from your taskbar or menu bar.

  2. 2

    Find your AFT stack (aft_backend, aft_db, aft_frontend) and click the Stop button.

  3. 3

    Wait 10 seconds, click Start, wait until all icons are green, then refresh http://localhost:5173.

Fix 2 • Free Up Laptop Power

Close Extra Tabs & Plug In Charger

  • Close heavy apps & extra browser tabs: Docker needs room in your laptop’s memory (RAM). Having 20+ Chrome tabs, video calls, or games open makes ANINAW lag.
  • Plug in your laptop charger: Windows and Mac laptops slow down their processor on Battery Saver / Low Power Mode, which slows down reports and PDF exports.
  • Give Docker 30–60 seconds after booting: Right after turning on your computer, wait until Docker Desktop finishes starting before opening the browser.
Fix 3 • Faster Saving

Keep Receipt Photos Reasonably Sized

High-resolution phone photos or multi-page scanner PDFs can be huge (4–5MB each), which slows down uploading and viewing receipts over time.

Tip: Send/compress receipt photos (for example via Messenger/compressed photo or a clean screenshot) so they stay clear to read without taking up several megabytes per file.

Important • Avoid Mistakes

What NOT To Do When It’s Slow

  • Don’t spam-click Save / Submit: If a button is spinning, wait a few seconds so you don’t submit duplicate entries.
  • Don’t delete the data/ folder or Docker volumes: That deletes your database and receipts!
  • Don’t click “Wipe All Data” in Settings: That permanently erases all financial records.
Step 5 of 5 • Account Rescue

Forgot Your Password? Reset Without Losing Data

Which account is locked out? Choose the matching option below.

Option A • No Commands Needed

Treasurer, Auditor, or Secondary User

  1. 1

    Ask anyone with an ADMIN login on your team to sign in to ANINAW.

  2. 2

    Open Settings → User Management.

  3. 3

    Click the Key icon (Reset Password) next to your username and enter a new password. Done!

Option B • Admin Lockout Rescue

Locked Out of the Main admin Account

First, try the default password admin123 in case it was never changed. If that says Invalid credentials, use the One-Command Rescue Tool below—it updates only the password and keeps 100% of your records safe.

Zero Data Loss Tool

Interactive Password Reset Command Builder

Type your new password below, copy the generated command, and run it once.

One-Line Reset Command (Safe • No Data Lost) 
docker exec -e NEW_PASS='YourNewPassword' aft_backend node -e 'const bcrypt=require("bcrypt"),{PrismaClient}=require("@prisma/client"),p=new PrismaClient();bcrypt.hash(process.env.NEW_PASS,10).then(h=>p.user.update({where:{username:"admin"},data:{passwordHash:h}})).then(u=>console.log("Updated password for:",u.username)).finally(()=>p.$disconnect())'
  1. 1
    Make sure ANINAW is open in Docker Desktop

    If using a “Running” option, check Docker Desktop and make sure aft_backend and aft_db are green/running.

  2. 2
    Open Terminal / PowerShell and Paste

    On Windows, press the Windows key, type PowerShell (or cmd if you picked Windows CMD), and press Enter. On Mac, open Terminal. Right-click to paste the command and press Enter.

  3. 3
    Confirm & Sign In

    When you see Updated password for: admin, refresh http://localhost:5173 and log in with your new password!

Quick Answers

Frequently Asked Questions

Will restarting Docker or resetting the admin password wipe our financial data?

No. All transactions, accounts, events, receipts, and users are saved inside your local data/ folder (or Docker’s pgdata volume). Restarting Docker Desktop or running the one-line password reset only changes that user’s password—nothing else is touched.

Why does it say “Invalid credentials” even when I type admin123?

Someone already changed the admin password after the first setup, or you are signing in to a newly created organization whose admin username/password was set by the Superadmin. Restarting the app keeps your changed password, so use the Password Reset Command Builder above to set a fresh password.

What if it says “Organization is disabled” when trying to log in?

If your school or council uses the multi-organization version of AFT, the platform Superadmin can temporarily enable or disable an organization’s access. Contact your Superadmin so they can toggle your organization back to ACTIVE.

Can I view all transactions in Microsoft Excel?

Yes! Two ways:

  • Inside ANINAW, open Financial Reports and click Export CSV (or Download PDF).
  • Inside your project folder, open data/reports/transactions_log.csv directly in Excel—it stays updated automatically as transactions are recorded.
What should I do if I entered the wrong amount on a transaction?

Open Journal, find the entry using the search bar, and click Edit or Void. ANINAW keeps an audit history of edits and voids so your Auditor can verify every change cleanly.

How do I turn the app off safely when I’m done for the day?

Just close your browser tab, or open Docker Desktop and click Stop on your AFT containers (or run docker compose down inside your AFT folder). Your data stays saved safely on your computer for next time.
